# Agta Pereira

Trabalho com análise de dados e automação para organizar bases, simplificar relatórios e criar indicadores que apoiem decisões.

## Como posso ajudar

| Necessidade | Solução |
| --- | --- |
| Planilhas desorganizadas ou inconsistentes | Limpeza, padronização e tratamento de dados |
| Dificuldade para acompanhar resultados | Dashboards e indicadores em Power BI |
| Tarefas repetitivas na preparação de relatórios | Automação com Python |
| Dados espalhados em diferentes fontes | Preparação e análise com Python, SQL e Excel |

## Projeto em destaque

### [Consumo Inteligente](https://github.com/agtavice-cloud/consumo-inteligente-hackathon)

**Problema:** transformar registros de compras em informações sobre os perfis de clientes.

**Solução:** preparação de dados, indicadores RFM, segmentação com K-Means e aplicativo interativo para consultar indicadores e recomendações por cliente.

**Ferramentas:** Python, SQL, Power BI e Streamlit.
